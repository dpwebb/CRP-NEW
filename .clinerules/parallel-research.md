# CRP parallel research configuration

Owner authorized Cline subagents, 2026-10-01.

Use up to three focused research subagents simultaneously when independent investigations can shorten an approved implementation batch. This is a workload limit, not a claim of a configured runtime concurrency setting.

The lead Cline agent alone edits files, applies governing amendments and integrates changes. Subagents perform read-only research and return concise findings, exact code paths and reusable interfaces. Avoid redundant investigations and nested delegation.

Suggested independent tracks: legacy rule/evaluator reuse; country/bureau extraction interfaces; application/account-isolation tests. Follow the approved immutable all-82 plan and the currently active order. Do not expand scope, override higher authority or overlap Codex file ownership.

Exclude credential files, secrets, environment files and private consumer reports from delegated tasks. Do not transmit report contents to model providers. Restrict research to authorized source code, sanitized metadata and synthetic fixtures. Inspect inherited commands for writes and network calls before running them; do not regenerate old evidence packages.

Do not change providers, models, auto-approval permissions or the active task merely to launch agents. Starting a new task may be necessary for settings to be recognized; let the current task finish first. Subagent support does not authorize multiple concurrent implementation writers.
